How to run

1) Offline (Python 3.10+)
   cd fear_mecanumbot
   python -m venv .venv
   pip install -r requirements.txt
   pytest -q
   python scripts/validate_dqn.py
   python scripts/validate_route_cost.py
   python scripts/v1_final_demo.py

2) Live MuJoCo (ROS 2 Humble, lab machine)
   export FEAR_DQN_MODEL=.../fear_mecanumbot/models/hri_dqn.npz
   bash scripts/wsl_e2e_dqn.sh

   Logs to expect:
   Fear action policy: dqn
   ALL BRICKS DONE — delivered 4

Weights: models/hri_dqn.npz
Eval: models/hri_dqn_eval.json
Log: evidence/EVIDENCE.txt
